# MagicSquare_260604 — 문제 정의 보고서 (01)

> 작성 기준: Mom Test 인터뷰 · STEP 1 워크북 · 슬라이드 4.1 (4×4 부분 마방진)  
> 도메인: **4×4 부분 마방진 · 빈칸 2개 · 10선 합 34**

---

## STEP 1 — Mom Test 요약

### 페르소나
프로그래밍 수업에서 **4×4 부분 마방진**(빈칸 2개, 1~16, 합 34) 과제를 받은 **학생**.

### Mom Test 증거 (과거·구체)
1. 「빈칸이 있는 **행부터** 네 칸씩 더해서 34가 되는지 봤어요.」
2. 「**행 4개·열 4개** … **주대각선(`\`)** 한 줄만 … ‘됐다’고 생각했어요.」
3. 「**반대 대각선(`/`)** … 34가 아니었어요. … **15분쯤** 더 썼어요.」

### 표면 문제 (잘못된 정의)
「4×4 부분 마방진 **검증/풀이 프로그램**(또는 ECB·UI **완성 앱**)을 만든다」

### 진짜 문제 (한 문장)
**빈칸 두 칸을 채운 뒤 행·열과 주대각선(`\`)만 확인하고 완료로 여겼고, 반대 대각선(`/`)을 빼먹어 조교에게 보이기 전에 틀림을 알게 되어 약 15분을 추가로 썼다.**

## STEP 3 — 세션 3 주제 (Mom Test 기반)

### 주제 한 문장 (솔루션 최소화)

**4×4 부분 마방진(빈칸 2개)을 풀 때 행·열·`\`만 맞다고 보고 `/` 검증을 빼먹어 시간을 낭비하는 문제를, 10선(합 34) 판정을 빠짐없이 확인할 수 있게 만든다.**

### R-G-I-O

| | |
|---|---|
| **Role** | 프로그래밍 수업에서 4×4 부분 마방진 과제를 받은 **학생** (손 계산 + 코드 검증) |
| **Goal** | 빈칸 2개를 채운 뒤 **10선**이 모두 34인지 판정; 틀리면 **어느 줄**(행/열/`\`/`/`)인지 즉시 식별 |
| **Input** | 4×4 정수 격자 (0=빈칸 **정확히 2개**), 1~16·중복 없음·크기 4×4 |
| **Output** | 10선 각 합 vs 34, 실패 시 **줄 종류·인덱스**, (후속) 빈칸 좌표·후보 판정 메시지 |

### 성공 기준 (Mom Test 연결)

| ID | 기준 | Mom Test 연결 |
|----|------|---------------|
| SC-1 | 입력 시 **10선 합 전부** 계산·표시 (행·열만 X) | 「행 4·열 4·**`\` 한 줄만**」→ **`/` 포함** 10선 전부 |
| SC-2 | 10선 중 하나라도 ≠34 → **실패 + 줄 식별** | 「**`/`** … 34가 아니었어요」 |
| SC-3 | 동일 유형에서 **15분 → 1분 이내** 원인 특정 | 「**15분쯤** 더 썼어요」 |

## STEP 5 — 문제 정의 (PRD 연결)

### 핵심 질문
> **"4×4 격자에서 빈칸 2개를 채운 결과가 부분 마방진 조건(10선=34)을 만족하는가?"**

### 판정 규칙
1. 격자 크기 4×4, 값 0 또는 1~16
2. 0(빈칸) **정확히 2개**
3. 1~16 **중복 없음** (빈칸 제외)
4. **10선** 각각 합 = 34

### 실패 시 반환 (개념)
- E001: 잘못된 크기
- E002: 빈칸 개수 ≠ 2
- E003: 범위/중복 위반
- E004: 특정 줄 합 ≠ 34 (줄 종류·인덱스 포함)
