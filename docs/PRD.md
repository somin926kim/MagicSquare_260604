# PRD — MagicSquare_260604 (4×4 부분 마방진)

## 1. 배경

프로그래밍 수업에서 **4×4 부분 마방진(빈칸 2개, 1~16, 합 34)** 과제를 풀 때, 학생이 빈칸을 채운 뒤 **행·열·주대각선(`\`)만** 확인하고 **반대 대각선(`/`)** 을 검증에서 빼먹어, 조교에게 보이기 전에 틀림을 알게 되고 **약 15분**을 추가로 쓴 사례가 있다(Mom Test).

본 PRD는 **"10선=34 판정을 빠짐없이·기계적으로 수행"** 하는 것을 1차 목표로 한다.

## 2. 목표

- 4×4 격자(빈칸 2개)에 대해 **10선 합이 34인지** 검증한다.
- 실패 시 **어느 줄(행/열/`\`/`/)** 이 깨졌는지 식별한다.
- 빈칸 좌표 탐색 및 후보 값에 대한 판정을 제공한다(Logic Track, 후속).

## 3. 비목표

- 완성된 PyQt 상용 앱 · 배포
- 3×3 / 5×5 / 마방진 자동 생성
- 세션 3에서 Domain GREEN·UI 구현 완료

## 4. 사용자

- **Primary:** 4×4 부분 마방진(빈칸 2개) 과제를 받은 프로그래밍 수업 **학생**
- **Secondary:** TDD/ECB 학습자 (Cursor 워크플로 실습)

## 5. 도메인 규칙

| 규칙 | 설명 |
|------|------|
| R-01 | 격자는 4×4 |
| R-02 | 셀 값: `0`(빈칸) 또는 `1..16` |
| R-03 | 빈칸(`0`)은 **정확히 2개** |
| R-04 | 1~16은 **중복 없음** (0 제외) |
| R-05 | **10선** 각각의 합 = **34** |
| R-06 | 10선 = 행 4 + 열 4 + `\` + `/` |
